# SoMerch Logo Usage

Basic public guidance for using the SoMerch logo.

---

## Correct usage

Use the official SoMerch logo files from:

`assets/logos`

When using the logo:

- keep the logo readable
- keep enough spacing around it
- use it on clean backgrounds
- use the correct brand name: SoMerch
- do not recreate the logo manually
- do not use unofficial logo variations

---

## Incorrect usage

Do not:

- stretch the logo
- rotate the logo
- crop the logo
- change the proportions
- add shadows or effects
- change colors without approval
- place it on busy backgrounds
- combine it with other logos in a misleading way
- use the logo to imply partnership without approval

---

## Clear space

Keep enough empty space around the logo so it remains readable.

As a simple rule, leave clear space around the logo equal to the height of the main text mark.

---

## Minimum size

The logo should always remain readable.

Avoid using it so small that the wordmark becomes unclear.

---

## Public usage

The SoMerch logo may be used in:

- media articles
- partner directories
- approved launch pages
- app listings
- public company references
- internal company vendor directories

For any usage that implies partnership, sponsorship, endorsement, or resale rights, please contact SoMerch first.

---

## Logo file recommendations

Recommended logo files:

- `somerch-logo.svg`
- `somerch-logo.png`
- `somerch-icon.png`
- `somerch-wordmark.png`

Use SVG when possible for web and partner pages.

Use PNG for platforms that do not accept SVG.

Do not upload font files to this repository.
